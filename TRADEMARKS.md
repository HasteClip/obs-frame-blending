# The HasteClip name and icon

The source code of HasteClip Frame Blending is free software under the GNU GPL
(see [LICENSE](LICENSE)). The name "HasteClip" and the HasteClip icon (the
horse and clapperboard) are not part of that license: they identify the
official HasteClip software made by Kaillr.

You're welcome to:

- say that your project is based on HasteClip Frame Blending, works with it,
  or compare itself to it;
- use the name and icon to write about or link to HasteClip.

Please don't:

- release a copy or changed version under the name HasteClip, or under a name
  or icon that could be mistaken for it;
- suggest that your version is official or endorsed by HasteClip.

If you fork it, give it your own name and icon. Questions: open an issue on
https://github.com/hasteclip/obs-frame-blending.
